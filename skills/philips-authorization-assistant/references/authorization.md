## 写入及截图

1. `lark-cli base +field-list --base-token ... --table-id ... --as user`；需要姓名人员字段时解析用户本人 ID，不把创建人或 bot 误当申请人；先用检索避免重复。附件类字段通过上传接口处理。
2. `lark-cli base +record-batch-create --base-token ... --table-id ... --json '{"create_records":[{...}]}' --as user`；字段值依实时 schema 与类型编码。获得 record_id 后使用 `+record-get`（必要时短暂重试以等待一致性）核对；附件通过 `+record-upload-attachment` 并再核对。`+record-share-link-create` 获取具体记录 URL。
3. 用可用的用户已登录浏览器／电脑操作工具打开上一步**真实飞书记录**或其分享页，定位完整的申请字段，确保所截记录的 record_id/主体与回读一致；若一屏不足就分多张截图。捕获原始界面并将真实截图作为当前对话图片或可访问的本地图片交付用户，说明可用于国内 OA 附件。不要捕获无关记录或将合成的 HTML、模拟界面、文字概览称为飞书截图。截图含业务资料，按实际使用场景裁切。
4. 没有可用已登录浏览器、界面无法展示或当前环境不能导出截图时：如实说明未取得截图；仍交付核对结果、该记录链接，并指出用户打开记录后自行截图。必要时请用户协助或接管浏览器。不要反复创建记录，也不要停止其他已授权任务。
5. 海外用户仍可获得截图和链接，明确其不需要 OA。不要主动通过飞书聊天发送给第三人；“发给我”优先在当前对话展示。
