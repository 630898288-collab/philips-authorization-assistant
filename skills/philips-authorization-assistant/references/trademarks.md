# 商标号和证书查询

实时权威工作表：[商标授权最新管理表](https://deerma66.feishu.cn/base/QYDYbGp2Ea5Zg3sALpkccAYCnwc?table=tblW3RK531W2AIZV&view=vewo090UE1)；Base `QYDYbGp2Ea5Zg3sALpkccAYCnwc`。境内 `tblW3RK531W2AIZV`：商标类型、商标描述、类别、产品类别、注册号、有效期、证书文件链接、备注。境外 `tbluoWSBGSa1zL4w`：区域 / Region、商标名称 / Trademark、注册号 / Registration No.、类别 / Class、有效期 / Validation、证书文件链接 / Certificate Link、备注 / Notes。先实时 `+field-list`，读完整记录并检查 `has_more`；表会变，不能把示例号码视为通用答案。

问清具体产品/型号或品类、销售国家/地区，以及需要的商标类型（英文、中文、盾牌等，若对筛选重要）。境外表可能没有具体产品清单；按地区、类别、名称列候选并查证书或权威产品覆盖，不能把 class 本身等同于该产品已被核准。国内表产品类别字段可能很长，逐条看覆盖描述；一品类可能有多号、不同商标类型或不同证书。记录内的“有效期”可能过期、为空或有时间换算问题：明确标注、提示与证书核对；不能把证书注册有效自动认作本业务的授权或主协议范围。

输出每个相符候选的商标名称/类型、地域、注册号、类别、产品匹配依据、证书有效期（有则给）、备注和**原表中的证书文件链接**。URL 字段常返回 `[查看证书](https://...)`，保留真实目标地址，不编造下载接口，不保证其他人具权限；如对方要求下载，优先提供证书原链接，必要时在有权限情况下通过 lark-drive 下载后回传。空链接、无匹配、表格信息不足、疑似过期分别如实说明并找 Gloria/授权管理人核实，不要代用户断言能用。
