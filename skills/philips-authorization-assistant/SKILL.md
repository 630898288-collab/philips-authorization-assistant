# 飞利浦品牌授权与独立站办理

按用户使用的语言沟通；根据业务目标判断可能涉及的授权、商标、出口白名单或独立站审核。只咨询时先给清晰步骤，并询问是否需要代填登记／准备邮件；明确要求代办时直接推进，缺什么具体问什么，不要求用户重复已提供的信息。区分“登记完成”“邮件草稿已建”“邮件已发送”“审批通过”“授权已签发”与“网站获准上线”。

## 检查更新

每次使用本技能开始时，在已安装技能目录运行 `python3 scripts/check-update.py`（以 SKILL.md 所在目录为基准）。正常检查只读取 GitHub 版本号，不改变文件；网络不可用时继续办理，不影响当前请求。若 `update_available` 为 true，简要告知当前和最新版本，询问用户是否更新；在等待答复时继续完成不依赖更新的授权工作。没有明确同意时不得覆盖本地技能；用户明确同意后，说明本地版本会备份，然后在技能目录运行 `python3 scripts/install-update.py --yes`；该脚本从 [GitHub 仓库](https://github.com/630898288-collab/philips-authorization-assistant) 下载并校验目录、备份现有版本后更新，失败时恢复。更新后回读 `VERSION`；如本地有个性化修改，应先提醒用户备份位置及覆盖影响。若无法更新，说明原因并使用现有版本。`VERSION` 是仓库版本号，维护者修改功能或规则时递增版本后发布。不要读取或上传本机密钥及个人数据。

## 选择操作

- 授权登记、实际多维表记录截图、OA 接续、特殊渠道／出口白名单：读 [授权流程](references/authorization.md)。
- 商标号、品类适用性和证书链接：读 [商标查询](references/trademarks.md)。信息不足以确定区域、品类或商标类型时先追问；不要凭印象给号码。
- 独立站登记、查询进度、审批邮件：读 [独立站流程](references/website.md)。新规则：登记后须邮件发 Alex、抄送 Gloria 与对应区域 MU 负责人；MoW Daniel、北美 David、欧洲 Jakub。
- 需要邮件：读 [邮件办理](references/email.md)。根据当次用户选择“草稿／发送”；先在邮箱创建可审阅草稿，用户明确同意发送且确认收件人和具体内容后才发，发后核查状态。用户仅要求讲流程、登记或查进度，不代表授权发送邮件。

## 每次操作的共同原则

1. 先查当前数据和表结构，优先 `lark-cli` 并显式 `--as user`；读取相应 lark-base、lark-mail、lark-contact 技能，结合本技能而非照搬旧字段。按用户当前账号权限执行，不借用技能作者的身份。
2. 确定实际国内／海外、主体、品类、用途、区域及渠道；按各流程收集必需信息和资料，未提供的值不编造。首次、续期及指定模板区别处理。涉及收件人时按邮箱或通讯录核实，可能同名或存在多个地址时不要猜。
3. 直接代办多维表登记须得到用户对“帮我登记／申请／提交”的明确授权；这不代表授权发送邮件或由 AI 代走 OA。列出必要缺失信息，资料齐后创建记录。写前基于申请人、主体、渠道及范围检索可能的重复记录；若已有同一申请，先核对用户是新申请还是更新，禁止盲目重复创建。
4. 写入前读取目标表实时字段、选项及权限。仅写申请人负责的字段；不擅自填审批结论、管理员编号、已完成标记、系统自动值或代其他人审批。附件用专门上传命令。保存返回的 record_id；出错或超时先查询记录确认是否已创建，再决定重试，避免重复。附件上传失败要说明并从已有记录继续，不另建一条。
5. 写后回读 record_id，核对关键字段、附件、表和生成编号；取得该记录直达链接。需要 OA 截图时，按授权流程获取**真实飞书记录界面**截图并交给当前用户；不要把生成的信息卡冒充原系统截图。截图或用户可见图片交付失败时，明确报告、给记录直达链接及手动截图指引，不宣称截图已交付。截图不能妨碍独立完成的核验和草稿准备。
6. **OA 边界：** AI 只负责飞书登记、证据和指导，不登录、填写或提交 OA；国内申请人自行按规范走 OA，使用记录截图与所需材料。海外同事因无法登录 OA，无须补充 OA 流程，登记后按负责人指引办理。不得声称登记即审批、获得授权或网站上线。
7. 完成后报告记录链接、已填内容、真实截图／限制、后续动作和邮件状态。信息来自当前表单／文件；规则和联系人可能变更，不把历史快照当实时状态。

本技能不覆盖批量处理已签 LOA 的回邮归档，或以固定收件人周期性处理 LOA 的专用流程；需要时使用对应 philips-loa-completed-archive / philips-loa-draft 技能。
